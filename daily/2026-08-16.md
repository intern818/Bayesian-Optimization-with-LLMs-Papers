# 贝叶斯优化 × LLM 每日论文速报

## 2026-08-16

> 今日目标：优先关注高水平会议中的 BO / BO×LLM 工作，再补充 arXiv、OpenReview 上尚未正式录取但具有明显研究价值的前沿工作。

## 🏆 高质量会议论文

### 1. CAKE — Adaptive Kernel Design for Bayesian Optimization Is a Piece of CAKE with LLMs

- **会议：** NeurIPS 2025 主会
- **相关性：** 9.8/10
- **核心创新：** LLM 不负责直接生成下一个 BO 点，而是负责 GP kernel 的 crossover / mutation；再通过 BAKER 结合 BIC 与 Expected Improvement 选择 kernel。
- **解决的问题：** 固定或人工设计 kernel 难以适应不同目标函数结构。
- **一句话评价：** 把 LLM 放到了 BO 的 surrogate/kernel 设计层，是典型的“LLM 作为 BO 算法设计器”。

### 2. BOLT — Scaling Multi-Task Bayesian Optimization with Large Language Models

- **会议：** ICLR 2026 Poster
- **相关性：** 9.7/10
- **核心创新：** 将历史 BO 任务的高质量解用于微调 LLM，让 LLM 为新任务生成 warm-start candidates；测试阶段仍由 single-task BO 完成精细搜索。
- **解决的问题：** 传统 Multi-Task BO 在任务数量达到数百甚至上千后，共享 surrogate 容易性能饱和。
- **一句话评价：** 很干净的“LLM 跨任务迁移先验 + BO 可靠 refinement”范式。

### 3. LMABO — Adaptive Acquisition Selection for Bayesian Optimization with Large Language Models

- **会议：** ICLR 2026 Poster
- **相关性：** 9.6/10
- **核心创新：** 用预训练 LLM 根据完整 BO state，在多个 acquisition functions 中动态选择当前最合适的策略。
- **解决的问题：** 没有单一 acquisition function 能在所有任务、所有优化阶段都最优。
- **一句话评价：** LLM 不生成 candidate，而是成为 BO 的高层“策略选择器”。

## 🧪 前沿预印本

### 4. Agentic Bayesian Optimization through Surrogate-Augmented Autoresearch

- **来源：** arXiv
- **相关性：** 9.9/10
- **核心创新：** LLM agent 成为 BO loop 的中央决策者，同时保留 Bayesian backend；agent 可以修改边界、切换 acquisition、增加 targeted evaluations，甚至重新定义优化问题。
- **解决的问题：** 传统 BO 难以利用自然语言、代码和文档中的非结构化领域先验；完全交给 LLM 又容易失去 BO 的系统性探索。
- **一句话评价：** 当前很值得跟踪的 Agentic BO 路线：Agent 做 orchestration，Bayesian backend 提供可靠的 uncertainty-aware search。

### 5. LABO — LLM-Accelerated Bayesian Optimization through Broad Exploration and Selective Experimentation

- **来源：** arXiv
- **相关性：** 9.5/10
- **核心创新：** 用廉价的 LLM prediction 大范围探索搜索空间，再通过 gating criterion 判断哪些位置值得付出昂贵的真实实验成本。
- **解决的问题：** 科学实验昂贵且数据稀缺，而 LLM evaluation 相对便宜，关键是合理分配两种 evaluation budget。
- **一句话评价：** 从“LLM 帮 BO 找点”进一步走向“LLM 作为廉价信息源，BO 决定何时相信它、何时调用真实 oracle”。

### 6. Multi-Agent LLMs for Adaptive Acquisition in Bayesian Optimization

- **来源：** arXiv
- **相关性：** 9.6/10
- **核心创新：** 将 strategy selection 与 candidate generation 拆成 Strategy Agent 和 Generation Agent；前者决定 exploration / exploitation 等搜索策略权重，后者根据策略生成候选。
- **解决的问题：** 单个 LLM 同时负责策略推理和候选生成容易产生 cognitive overload，导致不稳定和 premature convergence。
- **一句话评价：** 很贴近 Multi-Agent + BO：重点不是多个 agent 投票，而是把 BO 的不同决策层拆开。

## 🔥 今日研究趋势

今天最明显的趋势不是“LLM 取代 BO”，而是 **LLM 与 BO 的职责正在逐渐分层**：

1. **Kernel / surrogate 层：** CAKE 让 LLM 参与 GP kernel 设计；
2. **Initialization / prior 层：** BOLT 让 LLM 学习跨任务经验，为 BO 提供 warm start；
3. **Acquisition / strategy 层：** LMABO 让 LLM 动态选择 acquisition function；
4. **Agent orchestration 层：** Agentic BO 让 LLM agent 管理整个 BO loop；
5. **Evaluation 层：** LABO 让 LLM 提供低成本预测，把真实实验留给高价值候选；
6. **Multi-Agent 层：** 多个 agent 分担策略决策与 candidate generation。

### 一个值得关注的研究演化方向

> **LLM 正从“候选点生成器”逐渐变成 BO 的 prior / strategist / controller / agent。**

这条演化路线与你目前关注的 Multi-Agent、expert prior、LLM-enhanced BO 非常契合。
